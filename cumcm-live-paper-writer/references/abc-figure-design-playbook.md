# 国赛 A/B/C 论文图表设计手册

本手册将 A、B、C 题优秀论文中反复出现的图表功能提炼为原创赛时规则。目标是让图更能解释模型和结果，而不是复刻任何论文的配色、数据、图形或版式。

## 1. 先定义图的任务

每张图在绘制前填写：

| 字段 | 内容 |
|---|---|
| `figure_id` | `FIG-Q*-###` |
| `contrib_id` | `CONTRIB-Q*-###` 或 `N/A` |
| 本图唯一结论 | 一句可证伪陈述 |
| 读者要比较什么 | 位置、趋势、差异、分布、关系或过程 |
| 数据来源 | `RID-*`、CSV/JSON/MAT 路径 |
| 图型 | 选择理由 |
| 视觉编码 | x/y、颜色、线型、形状、大小 |
| 不确定性 | 区间、误差、重复或不适用 |
| 生成入口 | 脚本、函数、配置和命令 |
| 最终尺寸 | 单栏/双栏及宽高 |

若“本图唯一结论”无法写清，改成表格、正文数字或删除。

## 2. 按分析任务选图

| 要回答的问题 | 首选图型 | 可选增强 | 避免 |
|---|---|---|---|
| 数值随时间变化 | 折线 + 点 | 置信带、事件线、小多图 | 过多交叉折线 |
| 两变量关系 | 散点 | 拟合线、置信带、分组标记 | 只画拟合线 |
| 组间数值比较 | 排序点图/柱图 | 误差棒、基准线 | 非零起点柱图 |
| 分布差异 | 箱线/小提琴/ECDF | 原始点、分面 | 只报均值 |
| 类别构成 | 排序条形图 | 100% 堆积条 | 3D 饼图 |
| 相关结构 | 相关热力图 | 聚类排序、显著性标记 | 彩虹色带 |
| 空间场或参数场 | 等值线/热力图/地图 | 几何边界、采样点 | 无单位色条 |
| 几何与机理 | 矢量示意图 | 重点色、尺寸/角度标注 | 截图或装饰性 3D |
| 算法过程 | 流程图 | 关键状态、停止条件 | 把全部代码画进框 |
| 收敛与计算稳定性 | 目标/误差—迭代曲线 | 容差线、局部放大 | 仅写“已收敛” |
| 参数敏感性 | 单参数曲线/龙卷风图 | 基准点、稳定区间 | 只测两个端点 |
| 双目标权衡 | Pareto 前沿 | 推荐解、约束边界 | 只给单个最优点 |
| 方案排程 | 甘特图/时间线 | 冲突与容量标记 | 大段文字列表 |
| 网络与路径 | 网络图/路线图 | 权重、方向、关键节点 | 全连接毛线团 |
| 分类表现 | 混淆矩阵、ROC/PR | 阈值点、类别指标 | 只报准确率 |
| 预测表现 | 真实—预测、残差 | 区间覆盖、滚动窗口 | 训练集拟合冒充预测 |
| 证明差异化亮点 | baseline—主模型成对图/差异表/消融图 | 置信区间、效应量、失败边界 | 只画主模型或只标“提升” |

## 3. A/B/C 的功能图库

### A 题

- 坐标系、受力、光路、几何截面和边界示意图；
- 机理变量关系图；
- 空间分布、参数场、等值线和轨迹；
- 离散网格、时间步或采样精度收敛图；
- 观测值与机理模型曲线；
- 守恒误差、边界误差和独立算法对照。

示意图只用少量颜色：结构使用独立 chrome 深色（`text=#4F555A`），不要借用数据系列的 `neutral`；研究对象用主色，关键边界或方向用重点色。尺寸、角度、坐标轴和运动方向直接标注。

### B 题

- 算法流程图、状态转换图和二分/搜索时间线；
- 可行域、约束边界、路径、覆盖、排程和布局图；
- 目标值/最优间隙/违反量的收敛曲线；
- baseline 与候选方案的成对比较；
- 参数敏感性、情景矩阵和 Pareto 前沿；
- 方案结构与约束复核图。

流程图只保留输入、核心变换、判断、循环和输出；判断分支明确标“是/否”，终止条件必须可见。

### C 题

- 缺失、异常和样本结构的数据质量图；
- 排序条形图、箱线图、ECDF、分面直方图；
- 相关热力图和特征关系散点；
- 时间趋势、季节性、滚动均值和区间；
- 真实值—预测值、残差、误差分布；
- 分类混淆矩阵、ROC/PR 和阈值分析；
- 权重/排名敏感性和决策方案对比。

同一变量跨子图保持相同颜色。类别很多时优先排序条形图或小多图，不用饼图或一张图塞入十余条折线。

## 4. 建立统一视觉系统

工具提供四组已验证候选，不指定唯一默认。每支队伍必须在开始出图前显式选择一组，并把组名写入运行清单字段 `palette_set`；同一篇论文只能使用这一组，同一对象始终保持同一颜色、线型和标记。不得逐图更换或随机切换。

| 配色组 | 主色 | 对比色 | 辅助色 | 中性灰 | 重点色 | 可辨依据 |
|---|---|---|---|---|---|---|
| `SET-A` | `#2B495D` | `#B3A14B` | `#D0BADC` | `#818181` | `#B6303B` | 深海蓝—金黄—淡紫与强调红；L*≈29.59–78.28，最小相邻 ΔL*=12.09 |
| `SET-B` | `#692E6F` | `#53B474` | `#D7BCB7` | `#818181` | `#4C6C20` | 深茄紫—绿色—淡橙红与黄绿重点；L*≈29.68–78.36，最小相邻 ΔL*=12.04 |
| `SET-C` | `#5C402B` | `#939ED7` | `#AFCAA2` | `#818181` | `#1E6E67` | 深橙棕—蓝紫—淡绿与青色重点；L*≈29.71–78.44，最小相邻 ΔL*=12.12 |
| `SET-D` | `#2A4E26` | `#D38ABA` | `#A7C8CF` | `#818181` | `#7B41CD` | 深墨绿—品红—淡青蓝与靛紫重点；L*≈29.62–78.48，最小相邻 ΔL*=12.13 |

四组均按统一的 CIELAB L* 单调阶梯与逐组色相旋转设计，角色顺序为 `primary < accent < neutral < contrast < auxiliary`，相邻系列实测 ΔL* 均不低于 12；同一彩色角色在任意两组之间的实测色相环距离均不低于 60°，因此不同队伍选择不同组时具有可辨识的视觉差异，同时在灰度打印和色觉缺陷条件下仍能依靠明度分离。中性灰定位为次要/参考系列，不参与色相旋转。颜色仍不得作为唯一编码；线型、标记、纹理和直接标签仍是必需的冗余编码，而不是对配色缺陷的补救。最终图仍须逐张完成灰度与色觉缺陷 QA。连续数值使用所选组派生的顺序/双向色带；禁止 `jet`、彩虹和没有中心含义的红蓝色带。

风格基线：

- 白色背景，弱化上/右边框；
- 主数据线约 1.2–1.8 pt，参考线更细；
- 数据点约 4–6 pt，密集点可使用透明度；
- 网格只保留帮助读数的主网格，使用浅灰；
- 标题不重复正文和题注，优先把结论写进题注；
- 单位放在轴标签或色条，不散落在刻度；
- 小数位与论文表格口径一致；
- 图例按阅读顺序排列，能直接标注时省略图例。

## 5. 多子图的组织

- 子图回答同一个上位问题，否则拆图。
- 使用 `(a)(b)(c)`，题注逐项解释。
- 比较型子图共享轴范围；不共享时明确标出。
- 多子图只保留一个公共图例。
- 行列顺序遵循题目顺序、时间或模型流程。
- 最终尺寸下任一子图文字低于约 8 pt 时，减少子图或改放附录。

“丰富”来自互补证据，不来自一页塞满图。正文通常保留核心图，诊断图和全量分组图放附录。

## 6. 强化关键证据

根据任务添加：

- 原始点 + 拟合线 + 置信带；
- baseline、阈值、容量或零误差参考线；
- 最优点、拐点、异常点和失效点；
- 可行/不可行区域；
- 训练、验证、测试或政策阶段的背景分区；
- 误差棒、四分位区间或多 seed 分布；
- 收敛容差线与达到容差的迭代位置；
- 参数基准值和稳定区间。

### `CONTRIB-*` 亮点图表专用门

若图表用于把候选升级为 `PROVEN`：

- 图/表必须是专门证明产物，并绑定一个 `FIG-*` 或 `TAB-*`；
- baseline 与主模型使用相同数据、切分、指标、约束和视觉尺度；
- 直接标出差异量、区间或消融影响，不能让读者凭视觉猜测；
- 同时显示证伪阈值或失效边界，题注披露 `cost_risk`；
- 原始数据、全部 seed/情景和生成命令必须可回溯，禁止只画最好一次；
- 图表证据不支持 `claim` 时，将对应亮点设为 `DROPPED`，不得换标题继续使用。

标注只突出影响结论的对象，避免给每个点都贴标签。

## 7. 输出与版面规格

- 单栏图宽约 85–90 mm，双栏图宽约 170–180 mm；具体服从模板。
- 在最终插入尺寸检查字号，通常不低于约 8 pt。
- 线图、散点、流程图和几何示意优先导出 PDF/SVG 矢量文件。
- 含栅格场的图同时导出 300 dpi 以上 PNG。
- 背景使用白色；检查透明对象在 Word/PDF 中是否异常。
- 文件名使用 ASCII，例如 `fig_q2_sensitivity.pdf`。
- 图源数据、生成代码、配置和导出文件使用同一 `figure_id` 关联。

## 8. 题注与正文形成闭环

题注至少包含对象、条件、比较和必要的符号解释。正文按以下结构引用：

```text
图 n 显示……（结论）。
在……条件下，A 为……，相对 B ……（证据）。
这说明……（机制或决策含义）。
当……时该关系不再稳定（边界）。
```

不要写“结果如下图所示”后直接进入下一节。

## 9. 视觉 QA

从最终 PDF 而非绘图窗口检查：

- 图、题注和正文引用一致；
- 最终尺寸下文字、标记和线型可辨；
- 颜色映射跨图一致，灰度打印仍可区分；
- 图表登记已填写同一个 `palette_set`，没有逐图换组或混入默认高饱和循环色；
- 轴范围、对数尺度、单位和小数位正确；
- 柱图起点、轴断裂、平滑和归一化已披露；
- 图例未遮挡数据，色条有名称和单位；
- 误差带、可行域和重点标注不互相覆盖；
- 无广告、水印、个人路径、截图边框或软件界面；
- 图源数据和生成命令可重跑；
- 图不是关键数值的唯一载体。
- 作为亮点证据的图表能回到当前 `CONTRIB-PROVEN`，且正文中的量化 `proof` 与图源一致。

## 10. 必须淘汰的反模式

- 3D 饼图、爆炸饼图和渐变装饰；
- `jet`/彩虹色带；
- 截断纵轴夸大柱形差异；
- 双纵轴制造虚假同步；
- 用平滑曲线隐藏原始观测；
- 一张图放入过多相似折线；
- 子图很丰富但最终无法阅读；
- 不同图对同一对象使用不同颜色；
- 图中使用截图、低清文字或手工改数；
- 图后没有定量结论；
- 为“高级感”添加与结论无关的雷达图、桑基图或 3D 曲面。
