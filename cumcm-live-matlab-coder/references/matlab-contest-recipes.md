# MATLAB 赛时实现配方

本手册是 Skill 自带的原创工程与验证规则，不读取作者的 MATLAB 案例库或工具箱集合。代码必须按本届模型合同重新实现，并在当前机器上重新检查版本、工具箱、许可证和平台。

## 1. 函数优先结构

```text
contest-work/
├── config/
├── src/
├── tests/
├── inputs/
├── outputs/
├── figures/
└── logs/
```

- 主入口是接收配置结构体的函数，不依赖 base workspace。
- 文件名与首个函数名一致；小型辅助函数可放文件尾部。
- 只加入本次 `src` 和经过检查的最小依赖路径。
- 原始附件只读，派生结果写入独立目录。
- 禁止交互式弹窗、手工点击和隐式当前目录依赖。

## 2. 每次运行的环境预检

记录：

```matlab
version
computer
mexext
ver
which -all targetFunction
license('test', 'required_feature')
```

还要记录配置、输入 SHA-256、seed、批处理命令、开始/结束时间、日志和输出哈希。应用已安装不代表目标工具箱有许可证；函数可见也不代表没有路径遮蔽。

## 3. 确定性运行

- 入口执行 `rng(cfg.seed, "twister")`。
- 显式保存训练/验证索引和每次随机运行的 seed。
- 排序使用明确的列和方向，不依赖文件或结构体自然顺序。
- 启发式和仿真报告多 seed 分布，不挑最好一次。
- 新 MATLAB 进程使用 `-batch` 重跑后才能冻结。

## 4. 数据类型与字段断言

优先使用：

- `table`：异质表格数据；
- `timetable`：带时间索引且需重采样的数据；
- `categorical`：有限类别；
- `datetime`/`duration`：时间与间隔。

读取后检查：

```matlab
required = ["id","time","value"];
assert(all(ismember(required, string(T.Properties.VariableNames))));
assert(all(~ismissing(T.id)));
assert(height(unique(T(:, "id"))) == height(T), "id is not unique");
```

按合同补充类型、单位、范围、排序、缺失、重复、主键、时间频率和合并后行数检查。不要因方便而静默删行。

## 5. 矩阵与索引陷阱

- MATLAB 是 1 基索引；外部 ID 不一定等于数组位置。
- 明确行代表样本还是变量，写维度断言。
- 区分矩阵运算 `* / ^` 与逐元素 `.* ./ .^`。
- 隐式扩展前检查维度，避免无意生成巨大矩阵。
- 逻辑索引的长度必须与被索引维度一致。
- `squeeze` 可能删除意外维度，随后检查 `size`。
- 连接 table 前检查变量名、类型和行粒度。
- 字符、string 和 categorical 不混用为同一个键。

## 6. 求解器路线

| 结构 | 候选 | 必须检查 | 回退 |
|---|---|---|---|
| LP | `linprog` | `exitflag`、目标、约束余量 | 简化线性模型或可行 baseline |
| MILP | `intlinprog` | 整数性、间隙、时限、余量 | 松弛、固定变量、贪心 |
| QP | `quadprog` | Hessian 结构、状态、KKT/余量 | 线性或正则化近似 |
| NLP | `fmincon` | 多初值、局部性、原约束 | 分阶段或简化模型 |
| 回归/分类 | 可用的内置统计函数 | 数据切分、类别指标、许可 | 基础矩阵/透明规则 |
| 仿真 | 内置随机数与显式循环/向量化 | seed、收敛、边界 | 确定性上下界/情景 |

工具箱不可用时按模型合同回退，不临时加载来源不明的旧求解器、MEX 或工具箱。

## 7. 独立复核

求解器返回后另写检查逻辑：

```matlab
objCheck = c(:)' * x(:);
ineqViolation = max(A*x - b, 0);
eqViolation = abs(Aeq*x - beq);
assert(max(ineqViolation, [], "all") <= cfg.tol);
assert(max(eqViolation, [], "all") <= cfg.tol);
```

按实际模型补充变量界、整数性、互斥、覆盖、时间窗和守恒。预测指标也从最终预测表重新计算，不依赖模型对象中的训练摘要。

## 8. 数值原则

- 使用 `A\b` 或适当分解，不显式 `inv(A)*b`。
- 检查尺度、条件数、秩、零方差、NaN/Inf 和定义域。
- 大型稀疏约束优先用 sparse 矩阵。
- 浮点相等使用合同容差。
- 优化中的大常数必须有界且尽可能紧。
- 动力系统检查时间步收敛、守恒和边界。
- 计算概率、权重或转移矩阵后检查范围与行/列和。

## 9. 正确验证

| 数据关系 | 验证方式 |
|---|---|
| 独立分类/回归 | 分层或交叉验证 |
| 同一主体多条记录 | 分组切分 |
| 时间序列 | 前推或滚动验证 |
| 空间相关 | 分区/空间块切分 |
| 优化 | 小实例精确解 + 全约束复核 |
| 仿真 | 极端情景 + 多 seed + 重复数收敛 |

填补、标准化、降维和特征选择只能在训练部分拟合。模型合同未授权时不得根据最终测试结果反复调参。

## 10. 批处理与输出

推荐：

```bash
matlab -batch "run_case(load_config('config/run.json'))"
```

输出至少包括：

- `.mat` 原生结果；
- CSV/XLSX 机器可读表；
- 图对应的源数据；
- `exportgraphics` 生成的论文图；
- 环境、许可、配置、seed、日志和异常报告；
- 输入与输出哈希；
- 完整复现命令。

捕获异常时使用 `getReport(ME, "extended")` 写日志并返回失败状态。失败后不得继续生成看似正常的结果。

## 11. 安全与依赖边界

- 不加载外来 MEX、DLL、P-code、宏或未知二进制。
- 不对第三方目录执行递归 `addpath(genpath(...))`。
- 自定义依赖必须能确认源码、许可证、平台、版本和最小测试。
- 平台或许可证不匹配时直接回退，不尝试绕过。

## 12. 冻结与降级

- Baseline 与主模型必须使用同一输入、切分和指标。
- 主模型超时、异常、不稳定或未超过 baseline 时在切换时间前回退。
- 任何数据、代码、参数、版本、工具箱或许可变化都创建新 `run_id`。
- 新进程重跑、全部测试和输出合同通过后才标记 `FROZEN`。
