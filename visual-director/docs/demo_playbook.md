# 自媒体演示玩法

这个文档用于把 Skill 的能力包装成容易演示、容易传播、容易让粉丝索取的案例。

## 演示目标

让观众在 30-60 秒内看懂：

1. 普通人只给一个主题，也能得到专业图文方案。
2. Skill 不只是写文案，而是会判断风格、拆页面、做视觉提示词。
3. 同一个内容可以快速变成小红书图文、视频封面、知识卡片或产品卡片。
4. 输出能直接复制到图像工具或交给设计师继续做。

## 推荐演示结构

### 1. 先展示一个普通输入

例子：

```text
帮我把“普通人怎么用 AI 提升副业效率”做成一套小红书图文。
```

讲解重点：

- 输入很短，门槛低。
- Skill 会自己判断受众、目标和风格。

### 2. 展示 Skill 的核心判断

必须展示：

- 内容类型
- 传播目标
- 读者情绪
- 推荐风格
- 不推荐风格

讲解话术：

```text
普通 AI 可能直接给你 8 页文案，但这个 Skill 会先判断：这篇到底是要涨粉、收藏，还是转化。风格不是随便选的，是根据内容任务选的。
```

### 3. 展示页面结构

必须展示：

- Page 01 封面
- Page 02 痛点
- Page 04 方法
- Page 06 操作
- Page 08 引导

讲解话术：

```text
它不是把文字平均塞进 8 页，而是每一页只做一件事：封面负责停住人，内页负责讲清楚，结尾负责引导收藏和关注。
```

### 4. 展示提示词包

必须展示：

- 统一视觉母版
- Page 01 提示词
- 通用负面提示词

讲解话术：

```text
最有用的是这里：每一页都有可复制的视觉提示词，而且会锁定画幅、字体、边距、页码位置，避免生成出来每张都像不同模板。
```

### 5. 展示 Before / After

Before：

- 只有一个主题
- 风格不明确
- 不知道每页写什么
- 不知道怎么生成图

After：

- 有传播目标
- 有风格判断
- 有 8 页结构
- 有统一母版
- 有每页提示词
- 有标题、正文、标签、评论引导

## 30 秒口播模板

```text
很多人用 AI 做小红书图文，只会让它写 8 页文案，所以做出来特别像 PPT。

我现在用这个 Skill，只输入一个主题，它会先判断这篇内容是要点击、收藏还是转化，然后自动选视觉风格。

它会给我 8 页结构、每页标题、构图方式、统一视觉母版，还有可以直接复制到图像工具的提示词。

最关键的是，它会告诉你为什么这样设计，而不是只说“高级感”。

想要这个 Skill，可以评论区留关键词。
```

## 60 秒口播模板

```text
今天演示一个我最近在用的图文视觉 Skill。

很多人做小红书图文的问题不是不会写，而是不知道封面怎么抓人、内页怎么递进、风格怎么统一。

我给它一个很短的主题：[输入主题]。

它第一步不是直接写文案，而是先判断内容类型、传播目标、读者情绪和信息密度。

然后它给出 3 个风格方案：点击优先、收藏优先、个人品牌优先，并说明为什么推荐其中一个。

接着它把内容拆成 8 页：封面、痛点、认知、方法、案例、操作、总结、引导。

最后它会生成统一视觉母版和每页提示词，锁定画幅、边距、字体、色彩和页码位置，这样生成出来才是一整套图，不是 8 张不同模板。

如果你也想拿这个 Skill 去做自己的图文，评论区留关键词。
```

## 演示时避免

- 不要只展示长文案，观众看不出价值。
- 不要一上来就讲安装方法，先展示结果。
- 不要承诺一定涨粉、变现或爆款。
- 不要展示太复杂的商业项目，第一次演示要让普通人看懂。
- 不要把所有页面都念完，重点展示判断、结构和提示词。
