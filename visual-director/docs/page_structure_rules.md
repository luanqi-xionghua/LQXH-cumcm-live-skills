# 页面结构规则

## 基础原则

- 默认小红书 3:4 竖版；多页图文必须锁定同一目标画幅。小红书默认 `1080x1440px, strict 3:4 vertical portrait canvas`。
- 默认 8 页；用户指定页数时按用户要求。
- 一页只承担一个传播任务。
- 标题必须先被看见，正文必须服务标题。
- 手机端优先，正文尽量控制在 2-4 行。
- 页码、角标、装饰线不能抢过标题。
- 页面不能像普通 PPT 截图。

## 平台画幅选择

默认以小红书 3:4 为主；用户指定平台时按下表替换，不要硬套 3:4。

| 场景 | 推荐尺寸 | 页面重点 |
| --- | --- | --- |
| 小红书图文 | 1080x1440，3:4 | 封面抓点击，内页做收藏 |
| 抖音 / 快手图文 | 1080x1920，9:16 | 标题更大，正文更少，视觉冲击更强 |
| 口播视频封面 | 1080x1920，9:16 | 人物或主视觉更大，标题 2 秒读懂 |
| 16:9 横版图文 / 演示页 | 1920x1080，16:9 | 适合 B 站、视频插页、直播课、电脑端展示；要有主视觉，避免普通 PPT 感 |
| 知识卡片 / 朋友圈 | 1080x1080，1:1 | 单页一个观点，不做复杂长文 |
| 公众号封面 | 900x383 或 2.35:1 | 横向构图，一个标题 + 一个主视觉 |
| 电商详情头图 | 1080x1440 或 1080x1350 | 产品大图优先，卖点不超过 3 个 |

多平台复用时，先完成主版本，再输出改尺建议：

- 9:16 版本：标题上移，主视觉放大，删掉次要说明。
- 16:9 版本：标题放左侧或上方，主视觉放右侧或中部，正文压缩为 1-3 个模块。
- 1:1 版本：只保留核心观点和一个视觉锚点。
- 横版封面：标题压缩成一行或两行，减少装饰和正文。

## 16:9 横版规则

- 默认尺寸：1920x1080px，strict 16:9 landscape canvas。
- 安全边距：左右 120px，上下 90px；B 站封面或视频平台封面要额外避开右下角平台信息区。
- 标题区：左侧 35%-45% 或顶部 22%-30%，标题最多 2 行。
- 主视觉区：右侧或中部 40%-55%，要和标题直接相关，不能只是装饰。
- 正文区：最多 1-3 个短模块，不放长段落。
- 结构适合：左文右图、中心大标题 + 底部三卡、时间线、对比、流程、工具台截图。
- 禁止：普通 PPT 标题页、密集 bullet、左右平均分栏、没有主视觉、装饰线过多。

## 系列版式锁定

多页图文必须先定义一套“系列版式锁定”，并贯穿所有页面：

| 项目 | 默认规则 |
| --- | --- |
| 画布 | 小红书默认 1080x1440px，严格 3:4 竖版；其他平台按目标尺寸锁定 |
| 安全边距 | 左右 72px，上下 80px |
| 网格 | 12 列网格，8px 基准间距 |
| 标题区 | 顶部 18%-32%，封面可放大到 35%-45% |
| 正文区 | 最多 2-4 行，避免长段落 |
| 页码 | 固定同一角落，建议右下角，低权重 |
| 角标 | 固定同一位置，风格统一 |
| 卡片 | 圆角、边框、阴影、玻璃质感保持一致 |
| 线条 | 粗细、颜色、箭头样式保持一致 |
| 图标 | 统一线性图标或统一面性图标，不混用 |

允许变化：

- 主视觉位置和形态。
- 信息结构，例如对比、流程、清单、案例、总结。
- 局部强调词和小标签。

不允许变化：

- 页面比例。
- 安全边距。
- 字体系统。
- 主色和强调色。
- 页码 / 角标位置。
- 组件圆角和线条风格。

## 8 页默认结构

| 页码 | 页面任务 | 设计重点 |
| --- | --- | --- |
| 01 | 封面 | 强钩子、大标题、主视觉、清晰情绪 |
| 02 | 痛点 | 指出用户正在犯的错或忽略的问题 |
| 03 | 认知 | 解释为什么重要，建立判断框架 |
| 04 | 方法 | 给出结构、模型、步骤或系统 |
| 05 | 案例 | 展示具体例子，降低理解成本 |
| 06 | 操作 | 给可执行步骤，增强收藏价值 |
| 07 | 总结 | 收束观点，形成可复述金句 |
| 08 | 引导 | 收藏、评论、关注、下一篇预告 |

## 封面规则

- 标题占画面 30%-45%。
- 一屏只强调一个钩子，不要同时塞满卖点。
- 主视觉要和标题有关系，不能只是装饰。
- 要有清晰文字安全区，避免光效、纹理、图形干扰标题。
- 封面可以更冲击，但不能牺牲可读性。

## 内页规则

- 每页一个核心标题。
- 每页一个主要信息结构：对比、流程、架构、清单、案例、图表、标注。
- 内页之间要有节奏变化：不能 8 页都是中心大字，也不能 8 页都是卡片列表。
- 色彩、字体、角标和辅助线必须统一。
- 高信息密度内容必须拆页，不允许压缩字号硬塞。

## 结尾页规则

- 收束一句能被用户记住的话。
- 给明确行动：收藏、评论关键词、关注下一篇。
- 结尾视觉可以更简洁，像品牌签名。
- 不要用廉价二维码感或大促销感。
