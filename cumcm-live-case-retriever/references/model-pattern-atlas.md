# 内置模型模式图谱

本图谱是原创整理的通用建模决策卡，不包含历届论文、教材段落、第三方代码、真实案例结果或作者本机路径。它用于把“问题结构”匹配到候选方法，不证明某个模型适合本届题目。

## 使用方法

先建立六维问题签名：任务、数据、决策约束、动态性、不确定性、验收方式。按以下标准比较每张卡：

- 任务匹配 0–2 分；
- 数据形态匹配 0–2 分；
- 约束或机制匹配 0–2 分；
- 能否独立验证 0–2 分；
- 剩余时间与依赖风险 0–2 分。

只保留最高分主模式和最多两个辅助模式。每个候选都必须包含 baseline、验证和回退，并附加 `ROBUST-01` 与 `VALID-01`。领域名相似不计分。

每张模式卡同时输出 `differentiation_hint`，格式为：

```text
标准预期：评委最容易看到的透明 baseline 或常规交付。
差异方向：只有通过专门运行和验证才可能升级为 CONTRIB-PROVEN 的方向。
```

提示只给模型设计一个起点，不构成亮点、结果或论文证据。

## REL-01 关系估计与统计推断

- 适用信号：解释变量与响应变量、群体差异、影响因素、效应或置信区间。
- 最低数据：观察单位、变量尺度、组别/时间结构、缺失机制、可能混杂。
- Baseline：描述统计、散点/分布图、效应差和区间。
- 候选：线性或广义线性回归；重复测量或层级数据加入组效应；假设薄弱时用重抽样或非参数方法。
- 验证：残差、异常点、共线性、替代设定；同时报告效应量和不确定性。
- 失败信号：把相关写成因果；只报显著性；忽略组内相关；大量检验只挑显著结果。
- 回退：稳健区间或描述性结论，缩小因果表述。
- `differentiation_hint`：标准预期是相关分析、单一回归和显著性表；差异方向可放在效应异质性、替代设定稳健性、机制边界或可复核的反直觉分组结果。
- 输出：变量字典、估计表、区间、诊断图和因果边界。

## CLASS-01 有监督分类

- 适用信号：存在已知标签，需要识别、判定、筛选或预警。
- 最低数据：标签定义、每类样本量、特征产生时间、分组/时间关系。
- Baseline：多数类、透明规则、逻辑回归或浅树。
- 候选：正则线性模型、树集成、间隔分类器；不均衡任务使用类别权重和阈值。
- 验证：分层、分组或时间切分；混淆矩阵、宏 F1、平衡准确率、校准。
- 失败信号：只报准确率；切分前过采样；全数据选特征；同一主体跨集合。
- 回退：减少特征、简单规则或拒判区。
- `differentiation_hint`：标准预期是套用分类器并报告准确率；差异方向可放在与实际损失一致的阈值、概率校准、组外/时外泛化和关键误判机制。
- 输出：特征表、概率/标签、类别指标、阈值与误判分析。

## CLUSTER-01 聚类与群体画像

- 适用信号：没有标签，需要发现群体、画像、分层或异常簇。
- 最低数据：变量尺度、连续/类别类型、异常比例；删除纯编号变量。
- Baseline：稳健标准化后的简单 K-means 或规则分层。
- 候选：层次聚类、密度聚类、混合模型；按数据几何选择距离。
- 验证：重抽样或扰动后的成员稳定性；每簇必须能用原始变量解释。
- 失败信号：单一内部指数决定簇数；把算法簇当客观真相；混合变量直接用欧氏距离。
- 回退：降维后简单聚类，或输出规则分层与边界样本。
- `differentiation_hint`：标准预期是 K-means 加单一内部指标；差异方向可放在扰动稳定性、边界样本、混合变量距离和能落到决策上的群体画像。
- 输出：标签、中心/画像、稳定性、边界说明和可视化。

## FORECAST-01 时间序列预测

- 适用信号：按时间排列，目标是未来数值、趋势或区间。
- 最低数据：时间戳、频率、预测步长、缺口、异常、历史长度；外生变量在预测时可获得。
- Baseline：上一期、季节同期、均值或线性趋势，至少一条。
- 候选：指数平滑、低阶时间序列、带滞后特征的正则回归或树模型。
- 验证：前推或滚动验证；MAE/RMSE/相对误差；残差和区间覆盖。
- 失败信号：随机打乱；未来泄漏；全数据插值后切分；长周期窄区间。
- 回退：降低粒度、减少参数；主模型不稳定超过朴素法时正式采用 baseline。
- `differentiation_hint`：标准预期是选一个预测模型比较误差；差异方向可放在严格滚动验证、预测期可获得特征、区间校准、结构变化和跨时段泛化。
- 输出：切分、预测、误差、区间、残差和失效条件。

## EVAL-01 多指标评价与排序

- 适用信号：多个对象和指标，需要综合分数、等级、排名或优先级。
- 最低数据：对象—指标矩阵、单位、方向、缺失、指标含义。
- Baseline：统一方向、稳健标准化、等权加权和。
- 候选：客观权重与理想点距离；有可信偏好时才加入主观权重；强相关指标先去冗余。
- 验证：权重和为 1；方向正确；等权对照；扰动权重、删指标、换标准化。
- 失败信号：重复计分；极值支配；主观偏好伪装成客观；排名差异无法解释。
- 回退：稳健缩放后的等权模型；不稳定时报告等级或排名区间。
- `differentiation_hint`：标准预期是熵权/TOPSIS 给出单一排名；差异方向可放在指标去冗余、权重不确定性、排名稳定区间和面向决策的等级边界。
- 输出：指标字典、权重、得分、排名稳定性和敏感性。

## OPT-CONT-01 连续优化

- 适用信号：连续决策变量、目标函数、容量/预算/平衡等约束。
- 最低数据：变量单位和界、目标系数、约束、容差、可放松项。
- Baseline：现行方案、简单可行解或线性近似。
- 候选：线性、二次或平滑约束非线性优化。
- 验证：独立重算目标与逐条约束；缩小实例；多初值；区分局部与全局。
- 失败信号：量纲混乱；罚项掩盖原约束；求解停止被写成全局最优。
- 回退：分阶段、线性化、固定部分变量或交付最好已验证可行解。
- `differentiation_hint`：标准预期是把模型交给求解器并报告目标值；差异方向可放在独立约束审计、影子价格/结构解释、参数扰动下的可行性和可执行的鲁棒方案。
- 输出：决策、目标、约束余量、状态、baseline 对比。

## OPT-DISC-01 整数优化、调度与分配

- 适用信号：选择、开关、计数、顺序、时间窗、班次或指派。
- 最低数据：集合/索引、二元或整数变量、容量、先后关系、不可行处理。
- Baseline：构造式贪心或当前方案，先保证可行。
- 候选：混合整数规划、网络流、匹配；大规模使用构造解加局部改进。
- 验证：逐项验约束；小实例枚举/精确解；启发式报告多次分布而非最好一次。
- 失败信号：大常数导致数值问题；漏掉互斥/覆盖约束；可行写成最优。
- 回退：松弛、分解、固定变量、贪心加交换改进。
- `differentiation_hint`：标准预期是一个整数规划或启发式排程；差异方向可放在可行解构造保证、小实例最优性差距、方案韧性和决策结构的可解释规律。
- 输出：指派/时刻表、目标、余量、未服务项和最优性边界。

## MULTI-01 多目标与情景决策

- 适用信号：成本、效率、公平、风险冲突，或关键参数只有范围/情景。
- 最低数据：目标单位与方向、偏好或容忍阈值、参数区间、情景概率。
- Baseline：目标同向化与尺度统一后的透明加权和。
- 候选：约束化目标、Pareto 候选集、情景优化或区间鲁棒方案。
- 验证：支配关系、保守/基准/激进情景、权重与阈值敏感性。
- 失败信号：未标准化直接加权；任意权重；单一点声称完整 Pareto 解。
- 回退：固定首要目标，其余改成硬阈值；交付三套条件式方案。
- `differentiation_hint`：标准预期是固定权重得到一个折中解；差异方向可放在 Pareto 结构、偏好变化的决策区域、情景稳健性和何时应切换方案。
- 输出：权衡表、候选集、情景表现和选择条件。

## GRAPH-01 图网络、路径与网络流

- 适用信号：节点—边、连通、最短路径、运输容量、匹配或巡回访问。
- 最低数据：节点 ID、边方向、权重、容量、禁边、时间窗、坐标系、连通性。
- Baseline：小图手算、搜索或标准最短路并重建完整路径。
- 候选：生成树、网络流、匹配、整数路径模型或启发式巡回。
- 验证：逐边重算成本；检查方向、容量、起终点、重复访问；小图交叉核验。
- 失败信号：有向当无向；不适用负权算法；忽略不连通；经纬度直接作平面距离。
- 回退：分连通分量；最近邻加局部改进；明确未服务集合。
- `differentiation_hint`：标准预期是最短路、网络流或常规路径图；差异方向可放在关键边脆弱性、动态/容量耦合、断边情景和网络结构对方案的机制解释。
- 输出：图构造、路径/流量、总成本和约束核验。

## DYN-01 动力系统与机理模型

- 适用信号：状态随时间变化，存在守恒、反馈、扩散、增长或相互作用机制。
- 最低数据：状态定义、初值、边界、参数单位、观测时间和可识别信息。
- Baseline：简化差分递推、守恒关系或稳态近似。
- 候选：常/偏微分方程、状态空间或分区模型；复杂度受可识别性限制。
- 验证：量纲、守恒、边界、极端输入、参数识别、离散步长和残差。
- 失败信号：参数多于信息；拟合好但机制不可识别；数值误差被当作现象。
- 回退：减少状态/参数，使用上下界或情景范围。
- `differentiation_hint`：标准预期是拟合一组微分/差分方程；差异方向可放在可识别机理、参数区间导致的相变、守恒验证和可重复的反直觉动力学结论。
- 输出：方程、参数、轨迹、误差、敏感性和适用边界。

## SIM-01 Monte Carlo 与离散事件仿真

- 适用信号：排队、库存、传播、随机到达、复杂交互或不确定性传播。
- 最低数据：初始状态、转移规则、分布、时间步/事件、终止条件、观测指标。
- Baseline：用期望替代随机量的确定性递推或少量离散情景。
- 候选：离散事件、主体仿真或 Monte Carlo。
- 验证：守恒与边界、极端测试、多 seed、均值/分位数/区间、重复次数收敛。
- 失败信号：只跑一次；挑 seed；忽略预热；时间步过大；分布不匹配。
- 回退：确定性上下界、三情景或缩短范围。
- `differentiation_hint`：标准预期是 Monte Carlo 均值或单组仿真曲线；差异方向可放在不确定性分解、尾部风险、收敛效率、策略切换阈值和多 seed 稳定结论。
- 输出：规则、参数、配置、收敛图和情景统计。

## GEO-01 图像与计算几何

- 适用信号：像素、轮廓、面积、坐标、覆盖、遮挡、轨迹或空间距离。
- 最低数据：分辨率、物理尺度、坐标方向、标定、采集条件或标注协议。
- Baseline：阈值/连通域；解析距离、投影、凸包或包围盒。
- 候选：经典视觉和轮廓方法；只有标签量和泛化验证足够时才用学习模型。
- 验证：人工抽样；交并比/定位误差；已知尺度标定；阈值、噪声和分辨率扰动。
- 失败信号：像素当物理单位；坐标翻转；同图调参验证；重叠重复计数。
- 回退：人工/半自动关键点、规则区域、采样估计或几何上下界。
- `differentiation_hint`：标准预期是阈值分割或直接几何计算；差异方向可放在标定误差传播、尺度/噪声鲁棒性、解析与数值交叉验证和几何机制洞察。
- 输出：标定、流程、坐标/轮廓、误差和叠图。

## ROBUST-01 鲁棒性与敏感性

- 适用信号：所有主模式强制附加。
- Baseline：关键参数单因素扰动，加保守/基准/乐观三情景。
- 候选：重抽样、联合扰动、随机传播或最坏情景。
- 验证：同时检查指标、排名、类别或决策是否改变；报告脆弱参数和稳定区间。
- 失败信号：扰动范围无依据；相关参数独立抽样；只报平均值；无稳定判据。
- 回退：只使用区间与情景；不稳定时缩小结论或改成条件式建议。
- `differentiation_hint`：标准预期是单因素敏感性图；差异方向可放在联合扰动、结论翻转边界、脆弱参数排序和稳定决策区域。
- 输出：敏感性排序、稳定区间、情景矩阵和结论边界。

## VALID-01 统一验证门

所有拟提交模型必须同时通过：

1. 字段、单位、方向、样本范围和缺失检查；
2. 无时间、分组、空间或目标泄漏；
3. 与预先定义的 baseline 同口径比较；
4. 预测有样本外验证，优化有约束重算，仿真有多 seed，图模型有小图核验；
5. 关键结论通过敏感性和极端情景；
6. 数据版本、配置、环境、seed、停止条件和日志已记录；
7. 论文数字、图、表能逐项追到冻结输出。

主模型未稳定超过 baseline 时采用 baseline。无法独立验收时输出 `BLOCKED_VALIDATION`，不得用“结果看起来合理”替代证据。

`differentiation_hint`：标准预期是单一指标或直觉验证；差异方向可放在两条独立证据链、证伪实验、消融/约束重算和冻结复现的一致结果。

## 常见模型链

- 需求预测 → 资源配置；
- 综合评价 → 方案筛选 → 优化；
- 回归估计参数 → 情景仿真；
- 聚类分群 → 分群预测或策略；
- 图网络构造 → 路径/流量/调度；
- 图像测量 → 几何量 → 统计或优化。

链中每个中间产物都要有 schema、版本、误差和消费者。上游变化后下游全部标记 `STALE`。
